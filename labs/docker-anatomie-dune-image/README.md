# The anatomy of an image: layers, sharing, configuration

This lab is about what an image really holds: its layers, what it shares with
another one, and its configuration.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Images, containers and registries: the anatomy](https://www.stephane-robert.info/en/docs/docker/images-containers-and-registries/).
The mission is shown by `dsoxlab challenge docker-anatomie-dune-image`.
