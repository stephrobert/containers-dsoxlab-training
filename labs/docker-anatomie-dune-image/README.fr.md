# L'anatomie d'une image : couches, partage, configuration

Ce lab porte sur ce que contient vraiment une image : ses couches, ce qu'elle
partage avec une autre et sa configuration.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Images, conteneurs et registres : l'anatomie](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/anatomie/).
La mission s'affiche avec `dsoxlab challenge docker-anatomie-dune-image`.
