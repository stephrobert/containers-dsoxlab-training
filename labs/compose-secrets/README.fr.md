# Secrets fichiers accordés par service

Trois contrôles mesurent l'accord Compose, le montage réel en lecture seule et
le refus pour observer, les fuites de métadonnées ou journaux et la consommation
après rotation. Les jetons sont des valeurs pédagogiques, jamais des identifiants externes.
La rotation est le geste de l'apprenant, pas celui des tests : le lab pose la
valeur suivante, et les contrôles lisent l'état final. L'image fournie ne contient
pas le jeton ; le nettoyage retire uniquement les ressources de ce projet.
Les secrets fichiers autonomes ne promettent ni stockage chiffré ni protection contre root.
