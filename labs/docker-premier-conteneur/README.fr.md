# Lancer, arrêter, supprimer : trois verbes qui ne se recouvrent pas

Ce lab est le premier de la formation Docker. Il porte sur le cycle de vie d'un
conteneur : lancé, arrêté, supprimé. Un conteneur arrêté existe encore, et c'est
la distinction à maîtriser avant la suite.

Vous travaillez sur `docker.lab`, une Debian 13 où le moteur Docker tourne.
L'image nécessaire est déjà sur la machine.

Lisez d'abord la leçon : [Lancer un conteneur Docker et choisir ce qu'il exécute](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/cli/).
La mission s'affiche avec `dsoxlab challenge docker-premier-conteneur`.
