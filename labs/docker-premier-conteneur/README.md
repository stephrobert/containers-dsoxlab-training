# Run, stop, remove: three verbs that do not overlap

This lab is the first one of the Docker course. It is about the life cycle of a
container: started, stopped, removed. A stopped container still exists, and this
is the distinction to master before going on.

You work on `docker.lab`, a Debian 13 where the Docker engine runs. The image
you need is already on the machine.

Read the lesson first: [Run a Docker container and choose what it runs](https://www.stephane-robert.info/en/docs/docker/run-a-container/).
The mission is shown by `dsoxlab challenge docker-premier-conteneur`.
