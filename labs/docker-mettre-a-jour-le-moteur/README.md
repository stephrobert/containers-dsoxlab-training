# Move the engine up without the gateway noticing

This lab is about upgrading Docker Engine on a host that serves traffic.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Upgrade Docker Engine and back up its configuration](https://www.stephane-robert.info/en/docs/docker/upgrade-docker-engine-without-stopping-containers/).
The mission is shown by `dsoxlab challenge docker-mettre-a-jour-le-moteur`.
