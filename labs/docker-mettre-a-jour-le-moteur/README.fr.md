# Monter le moteur sans que la passerelle s'en aperçoive

Ce lab porte sur la montée de version de Docker Engine sur un hôte qui sert du
trafic.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Mettre à jour le moteur et sauvegarder sa configuration](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/mettre-a-jour-le-moteur/).
La mission s'affiche avec `dsoxlab challenge docker-mettre-a-jour-le-moteur`.
