# Give a service back the one capability it really needs

This lab is about the privileges of a containerised service, reduced to the
bare minimum.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Harden the runtime: capabilities and privileges](https://www.stephane-robert.info/en/docs/devsecops/containers-iac/docker-security/).
The mission is shown by `dsoxlab challenge securite-capabilities`.
