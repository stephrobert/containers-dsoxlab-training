# Rendre à un service la seule capability dont il a besoin

Ce lab porte sur les privilèges d'un service en conteneur, réduits au strict
nécessaire.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Durcir le runtime : capabilities et privilèges](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/securite/).
La mission s'affiche avec `dsoxlab challenge securite-capabilities`.
