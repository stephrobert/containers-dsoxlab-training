# ENTRYPOINT and CMD: which one do your arguments replace?

This lab is about two instructions of an image, `ENTRYPOINT` and `CMD`, and
what becomes of them when `docker run` receives arguments.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Run a Docker container and choose what it runs](https://www.stephane-robert.info/en/docs/docker/run-a-container/).
The mission is shown by `dsoxlab challenge container-entrypoint-et-cmd`.
