# ENTRYPOINT et CMD : lequel vos arguments remplacent-ils ?

Ce lab porte sur deux instructions d'une image, `ENTRYPOINT` et `CMD`, et sur
ce qu'elles deviennent quand `docker run` reçoit des arguments.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Lancer un conteneur Docker et choisir ce qu'il exécute](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/cli/).
La mission s'affiche avec `dsoxlab challenge container-entrypoint-et-cmd`.
