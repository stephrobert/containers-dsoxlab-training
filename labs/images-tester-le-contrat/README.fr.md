# Écrire les tests qui refusent une image cassée

Ce lab porte sur les tests d'une image : accepter celle qui est correcte,
refuser celles qui sont cassées.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Tester le contrat d'une image](https://www.stephane-robert.info/docs/conteneurs/images-conteneurs/tester-une-image/).
La mission s'affiche avec `dsoxlab challenge images-tester-le-contrat`.
