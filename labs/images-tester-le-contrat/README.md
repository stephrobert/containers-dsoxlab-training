# Write the tests that turn a broken image away

This lab is about testing an image: accepting the correct one, turning the
broken ones away.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Test the contract of an image](https://www.stephane-robert.info/en/docs/docker/test-an-image-contract/).
The mission is shown by `dsoxlab challenge images-tester-le-contrat`.
