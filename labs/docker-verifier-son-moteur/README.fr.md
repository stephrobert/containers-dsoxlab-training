# Le moteur fonctionne-t-il vraiment ? Quatre réponses, pas une

Ce lab porte sur l'état d'un moteur Docker fraîchement repris : est-il
réellement utilisable ?

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Installer Docker Engine 29 et prouver qu'il fonctionne](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/installation/).
La mission s'affiche avec `dsoxlab challenge docker-verifier-son-moteur`.
