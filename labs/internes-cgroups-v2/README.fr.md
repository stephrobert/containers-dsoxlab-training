# Les cgroups : ce qu'un conteneur peut consommer

Ce lab porte sur les cgroups, par lesquels le noyau limite ce qu'un conteneur
consomme.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Namespaces et cgroups : mesurer l'isolation d'un conteneur](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/sous-le-capot/).
La mission s'affiche avec `dsoxlab challenge internes-cgroups-v2`.
