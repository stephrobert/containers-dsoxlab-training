# Identité d'une image : le tag ment, le digest non

Ce lab porte sur l'identité d'une image : savoir laquelle tourne, quel que soit
son tag.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Lire une image OCI et son identité](https://www.stephane-robert.info/docs/conteneurs/images-conteneurs/identite-d-une-image/).
La mission s'affiche avec `dsoxlab challenge images-identifier-image`.
