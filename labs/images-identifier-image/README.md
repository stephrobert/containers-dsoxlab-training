# Image identity: the tag lies, the digest does not

This lab is about the identity of an image: knowing which one runs, whatever
its tag.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Read an OCI image and its identity](https://www.stephane-robert.info/en/docs/docker/read-an-oci-image-and-its-identity/).
The mission is shown by `dsoxlab challenge images-identifier-image`.
