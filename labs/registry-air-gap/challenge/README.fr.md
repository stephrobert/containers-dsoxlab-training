# Mission : livrer une image utilisable hors ligne

Emballez le produit publié dans `livraison.tar` avec son reçu SHA-256 portable.
Un lecteur indépendant doit le récupérer et l'exécuter après l'arrêt du
registre d'origine, sans emprunter les couches du cache Docker.

Le [scénario](../scenario.fr.md) donne les chemins de livraison et le tag attendu.
