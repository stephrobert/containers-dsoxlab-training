# Shared memory and descriptors

This lab is about two rarely checked defaults of a container: shared memory and
the number of open files.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Cap a container: CPU, ulimits and shared memory](https://www.stephane-robert.info/en/docs/docker/limit-a-container/).
The mission is shown by `dsoxlab challenge container-ulimits-et-shm`.
