# Exigences

1. Publier l'index de release à la référence de la mission.
2. Inclure exactement Linux AMD64 et Linux ARM64, avec des manifestes distincts.
3. Exécuter le calcul fourni et le refus d'entrée sur les deux variantes.
4. Préciser qu'ARM64 tourne sous QEMU, pas sur du matériel ARM64 natif.
5. Préserver le registre en boucle locale et les objets des autres apprenants.

`dsoxlab check images-multi-architecture` mesure les trois premières exigences.
Le formateur évalue l'explication séparément.
