# Ce qui vient du socle ne se retire pas

Ce lab porte sur le contenu d'une image finale, et sur ce qui lui vient de son
image de base.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Séparer construction et exécution : le build multi-étapes](https://www.stephane-robert.info/docs/conteneurs/images-conteneurs/build-multi-etapes/).
La mission s'affiche avec `dsoxlab challenge images-build-multi-etapes`.
