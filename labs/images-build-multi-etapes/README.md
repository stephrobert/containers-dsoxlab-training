# What comes from the base cannot be removed

This lab is about what a final image holds, and what comes to it from its base
image.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Separate build from runtime: the multi-stage build](https://www.stephane-robert.info/en/docs/docker/build-in-multiple-stages/).
The mission is shown by `dsoxlab challenge images-build-multi-etapes`.
