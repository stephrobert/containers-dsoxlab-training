# Where Docker stores a container's files

This lab is about where the engine stores a container's files on the host.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Docker volumes: keep your data and mount files](https://www.stephane-robert.info/en/docs/docker/keep-data-and-mount-files/).
The mission is shown by `dsoxlab challenge internes-stockage-des-images`.
