# Trois accès refusés, trois causes

Ce lab porte sur trois accès refusés qui se ressemblent et n'ont pas la même
cause.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Droits sur un volume Docker : trois causes courantes d'un accès refusé](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/droits-sur-un-volume/).
La mission s'affiche avec `dsoxlab challenge troubleshoot-permission-refusee`.
