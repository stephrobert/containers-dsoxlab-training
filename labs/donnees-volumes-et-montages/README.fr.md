# Où les données survivent : les trois types de montage

Ce lab porte sur l'endroit où un conteneur écrit, et sur ce qui survit à sa
suppression.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Volumes Docker : conserver ses données et monter des fichiers](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/volumes/).
La mission s'affiche avec `dsoxlab challenge donnees-volumes-et-montages`.
