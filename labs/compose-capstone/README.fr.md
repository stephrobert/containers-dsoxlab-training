# Capstone Compose

Ce lab vérifie une stack complète à deux services : un producteur ponctuel qui
réussit, des données nommées partagées, l'ordre de démarrage, un montage web en
lecture seule, la santé et un point d'accès limité à la boucle locale. Le test
fonctionnel recrée uniquement web et confirme que les données restent servies.

Lancez le nettoyage normal avant de rejouer le lab. Il retire uniquement les
conteneurs, réseaux, volumes et l'image portant les labels de ce lab.
