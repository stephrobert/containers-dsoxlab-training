# Back up a Compose stack, and restore it elsewhere

This lab is about backing up a running Compose application, database and served
files, and proving it can be restored elsewhere.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Back up and restore an application](https://www.stephane-robert.info/en/docs/docker/back-up-and-restore-a-compose-application/).
The mission is shown by `dsoxlab challenge compose-sauver-et-restaurer`.
