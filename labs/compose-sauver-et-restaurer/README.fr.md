# Sauvegarder une stack Compose, et la restaurer ailleurs

Ce lab porte sur la sauvegarde d'une application Compose en marche, base et
fichiers servis, et sur la preuve qu'elle se restaure ailleurs.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Sauvegarder et restaurer une application](https://www.stephane-robert.info/docs/conteneurs/orchestrateurs/docker-compose/sauvegarder-et-restaurer/).
La mission s'affiche avec `dsoxlab challenge compose-sauver-et-restaurer`.
