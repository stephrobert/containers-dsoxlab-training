# Mission : récupérer sans divulguer

Sur `docker.lab`, corrigez `/opt/lab-buildkit-secret/appli/Dockerfile` et construisez
`dsoxlab-secret:finale`. Récupérez le produit privé avec un secret BuildKit
éphémère, pas un argument de build ni un identifiant copié.

Le [scénario](../scenario.fr.md) donne l'adresse du dépôt et les critères.
