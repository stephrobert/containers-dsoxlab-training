# A namespace is a view, not a wall

This lab is about the namespaces the kernel gives a container, and what Docker
does not isolate.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Namespaces and cgroups: measure a container's isolation](https://www.stephane-robert.info/en/docs/docker/measure-container-isolation/).
The mission is shown by `dsoxlab challenge internes-namespaces`.
