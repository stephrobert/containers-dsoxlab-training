# 'Up' says nothing about the service

This lab is about the health of a service: a running container is not
necessarily a service that answers.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Test the contract of an image](https://www.stephane-robert.info/en/docs/docker/test-an-image-contract/).
The mission is shown by `dsoxlab challenge images-healthcheck`.
