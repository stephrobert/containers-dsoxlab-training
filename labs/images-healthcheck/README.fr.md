# « Up » ne dit rien du service

Ce lab porte sur la santé d'un service : un conteneur en marche n'est pas
forcément un service qui répond.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Tester le contrat d'une image](https://www.stephane-robert.info/docs/conteneurs/images-conteneurs/tester-une-image/).
La mission s'affiche avec `dsoxlab challenge images-healthcheck`.
