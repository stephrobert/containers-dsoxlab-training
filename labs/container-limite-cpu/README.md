# Capping a processor, and proving it

This lab is about the CPU limits of a container: what they change, what they do
not, and how to measure their effect.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Cap a container: CPU, ulimits and shared memory](https://www.stephane-robert.info/en/docs/docker/limit-a-container/).
The mission is shown by `dsoxlab challenge container-limite-cpu`.
