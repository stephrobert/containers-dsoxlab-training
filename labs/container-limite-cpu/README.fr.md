# Brider un processeur, et le prouver

Ce lab porte sur les limites de processeur d'un conteneur : ce qu'elles
changent, ce qu'elles ne changent pas, et comment mesurer leur effet.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Brider un conteneur : processeur, ulimits et mémoire partagée](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/brider-un-conteneur/).
La mission s'affiche avec `dsoxlab challenge container-limite-cpu`.
