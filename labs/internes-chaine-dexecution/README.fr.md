# Qui lance vraiment un conteneur

Ce lab porte sur la chaîne de programmes qui mène du démon Docker au processus
d'un conteneur.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Qui lance un conteneur : la chaîne d'exécution de Docker](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/chaine-d-execution/).
La mission s'affiche avec `dsoxlab challenge internes-chaine-dexecution`.
