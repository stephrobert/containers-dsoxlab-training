# Who really starts a container

This lab is about the chain of programs that leads from the Docker daemon to a
container's process.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Who launches a container: Docker's execution chain](https://www.stephane-robert.info/en/docs/docker/container-execution-chain/).
The mission is shown by `dsoxlab challenge internes-chaine-dexecution`.
