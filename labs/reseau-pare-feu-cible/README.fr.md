# Réparer un flux routé sans retirer les protections

Ce lab porte sur un flux réseau coupé entre un client, un routeur et un
serveur, à rétablir sans affaiblir le pare-feu.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Diagnostiquer réseau et pare-feu](https://www.stephane-robert.info/docs/conteneurs/moteurs-conteneurs/docker/reseau-et-pare-feu/).
La mission s'affiche avec `dsoxlab challenge reseau-pare-feu-cible`.
