# Repair one routed firewall path without dropping protections

This lab is about a network flow cut between a client, a router and a server,
to be restored without weakening the firewall.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Diagnose Docker network and firewall issues](https://www.stephane-robert.info/en/docs/docker/diagnose-docker-network-and-firewall-issues/).
The mission is shown by `dsoxlab challenge reseau-pare-feu-cible`.
