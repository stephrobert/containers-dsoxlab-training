# Ce qu'une couche garde

Ce lab porte sur le poids d'une image, y compris ce qu'un conteneur ne montre
pas.

Vous travaillez sur `docker.lab`, une machine virtuelle jetable.

Lisez d'abord la leçon : [Inspecter et réduire une image Docker sans la casser](https://www.stephane-robert.info/docs/conteneurs/images-conteneurs/optimiser-taille-image/).
La mission s'affiche avec `dsoxlab challenge images-optimiser-la-taille`.
