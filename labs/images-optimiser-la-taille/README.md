# What a layer keeps

This lab is about the weight of an image, including what a container does not
show.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Inspect and shrink a Docker image without breaking it](https://www.stephane-robert.info/en/docs/docker/inspect-and-shrink-an-image/).
The mission is shown by `dsoxlab challenge images-optimiser-la-taille`.
