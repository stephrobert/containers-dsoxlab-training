# Two containers, one volume, rights that hold

This lab is about the rights of a volume that two non-root containers share.

You work on `docker.lab`, a throwaway virtual machine.

Read the lesson first: [Docker volume permissions: three common causes of an access denied](https://www.stephane-robert.info/en/docs/docker/volume-permissions/).
The mission is shown by `dsoxlab challenge donnees-permissions-uid-gid`.
