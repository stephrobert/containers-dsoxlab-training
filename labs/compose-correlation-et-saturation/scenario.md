# Which component is saturated?

A quote API consists of the supplied gateway and CPU calculator. Its traces
cannot reconstruct a request and its current deployment exposes headers.
Configure the stack in `/opt/dsoxlab-compose-correlation-et-saturation`,
without rewriting either application.

Measure bounded business load, identify the saturated component from effective
cgroup counters and preserve fresh end-to-end request identities. Never retain
Authorization headers or the test witness in logs.
